# Mr-Ex School Website

Website for **Mr-Ex School** (Pre-Primary to Grade 5), *Rooted in Values, Driven by Vision.*

A single-page site with eight sections (Home, About, Learning, Campus, Uniform, School Life, Admissions, Contact), animated page transitions, scroll effects and an admission enquiry form.

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Before going live
- Add the school address, phone, email and website (currently shown as "Coming soon").
- Connect the enquiry form to an email service or backend; it currently only validates input.
- Confirm the admission steps, required documents and FAQ answers.
